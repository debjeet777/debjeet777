## 🧪 Current Research & Engineering

### 🔐 EntraNHI

**Open-source security engineering for Microsoft Entra non-human identities, workload identities and AI agents.**

[![Repository](https://img.shields.io/badge/Repository-EntraNHI-181717?style=flat-square&logo=github)](https://github.com/debjeet777/entra-nhi)
![Status](https://img.shields.io/badge/Status-Research_%26_Implementation_Design-7C3AED?style=flat-square)
![Security](https://img.shields.io/badge/Approach-Security_First-0A66C2?style=flat-square)
![License](https://img.shields.io/badge/License-Apache--2.0-green?style=flat-square)

EntraNHI is an active open-source engineering project exploring **deterministic security assessment of Microsoft Entra non-human identities**.

Current work is focused on the engineering foundation: **product research, requirements, architecture, threat modelling and implementation design**.

The project is being designed around several core principles:

- deterministic and explainable security assessment
- explicit assessment-completeness semantics
- evidence and provenance
- capability-aware evaluation
- false-PASS resistance
- read-only assessment
- provider isolation
- tenant-scoped processing
- strict secret exclusion
- adversarial and security-oriented testing

> **Current maturity:** research, requirements and architecture are established; implementation design is in progress. Production implementation has not yet begun.

**→ [Explore EntraNHI](https://github.com/debjeet777/entra-nhi)**

## ⚙️ Engineering Principles

| Security & Trust | Engineering Discipline |
|---|---|
| Security by Design | Deterministic Systems |
| Least Privilege | Evidence-Driven Engineering |
| Explicit Trust Boundaries | Automation over Repetition |
| Threat Modelling | Maintainability |
| Secure Software Supply Chain | Documentation as Engineering |

I prefer systems where security-critical decisions remain **explicit, inspectable and testable**.

AI can assist engineering, analysis and automation, but authentication, authorization, policy enforcement and other security-critical decisions should remain governed by deterministic controls.
